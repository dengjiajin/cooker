# 到家服务平台底座任务决策

- 系统长期按四个稳定域组织：`用户域`、`服务者域`、`交易域`、`平台治理域`
- 第一期先做平台底座，不直接交付完整业务平台
- 用户必须先完成微信登录和手机号授权，才能申请成为厨师
- 厨师是用户扩展出的身份，每个厨师都必须能映射回一个用户
- 后管登录是独立账号体系，且后管只有管理员可以登录
- 后管权限按完整 `RBAC + sa-token` 落地，不做阉割版
- 客户端入驻申请入口放在“我的”页面，不单独做 Tab
- 厨师申请必填字段：手机号、姓名、身份证号
- 厨师申请选填字段：性别、本人照片、厨师证、城市、擅长菜系、从业年限、个人简介
- 厨师默认密码固定为 `666666`，数据库只存哈希和盐值，首次登录强制改密
- 后管用户管理和厨师管理支持修改、启用、禁用，不支持手工新增
- MySQL 业务表默认使用 `creator`、`create_time`、`updater`、`update_time`
- 是否加入逻辑删除字段，需要按具体表和你逐个确认
- 已确认技术栈：
  - 后端：`Spring Boot 3 + MyBatis-Plus + MySQL + Redis + Sa-Token`
  - 后管 Web：`Vue 3 + Vite + TypeScript + Element Plus + Pinia`
  - 小程序：原生微信小程序
- 记忆类与规划类 Markdown 默认使用中文
